# Library Management System (Java - Command Line)

This is a simple Library Management System implemented in Java using a command-line interface. It demonstrates the use of object-oriented programming, clean architecture, and basic user interaction without any external libraries or frameworks.

---

## Overview

The application allows a librarian or user to:

- Add new books and members (internally for now).
- Display available books.
- Borrow a book by providing a Book ID and Member ID.

This project is structured into clearly defined packages (`model`, `service`, and `utils`) to reflect modular software design principles.

## Features

- Add and manage books and members
- Display all available books
- Borrow books by ID (book availability managed)
- Modular codebase with clear separation of concerns
- Includes basic file utility methods for future expansion (e.g., persistence)

---

## Requirements

- Java Development Kit (JDK) 8 or higher
- Command Prompt / Terminal
- Git (for version control)
